Filter State API - Test Page

这是一个零依赖的测试页，用于验证 window.filterState API 的正确性。

📚 API 文档

// 筛选状态读写 window.filterState.getFilters() // → { startDate, endDate, panoOnly } window.filterState.setFilters({ startDate: '2024-01-01', panoOnly: true }) window.filterState.getLayers() // → { points, signs } window.filterState.setLayers({ points: true, signs: false }) // Query 序列化/反序列化 window.filterState.toQuery() // → "startDate=2024-01-01&panoOnly=true&layers=points" window.filterState.fromQuery("startDate=2024-01-01&panoOnly=true") // URL 持久化 window.filterState.pushToUrl() // 推送到 URL window.filterState.restoreFromUrl() // 从 URL 恢复 // 版本和状态 window.filterState.getVersion() // → 当前筛选版本号 window.filterState.isReady() // → 地图是否就绪 window.filterState.reset() // → 重置为默认状态

手动验证步骤（浏览器回退/前进）：

1. 打开主页面 index.html 2. 开启 Points 图层 → 观察 URL 变为 ?layers=points 3. 开启 Signs 图层 → 观察 URL 变为 ?layers=points,signs 4. 点击浏览器"回退"按钮 → 验证： - URL 变为 ?layers=points - Points 开启，Signs 关闭 5. 点击浏览器"前进"按钮 → 验证： - URL 变为 ?layers=points,signs - Points 开启，Signs 开启 补充验证（筛选）： 1. 打开 Filters 面板，设置 startDate=2024-01-01，勾选 panoOnly 2. 点击 Apply → 观察 URL 包含 startDate 和 panoOnly 3. 点击 Reset → 观察 URL 恢复 4. 点击"回退" → 验证筛选状态恢复 5. 点击"前进" → 验证筛选状态重置
